# OpenSpec

Spec-driven development. Stable capabilities live in `specs/<capability>/spec.md`; each change lives
in `changes/<change-id>/` with `proposal.md`, optional `design.md`, `tasks.md`, and spec deltas under
`specs/`. Validate with `openspec validate` and archive shipped changes with `openspec archive`.

Until the `openspec` CLI is installed (see `make doctor`), these files are maintained manually.
